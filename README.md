# Waras Finansial

Platform edukasi literasi keuangan dan antarmuka simulasi deteksi penipuan investasi berbasis web. Proyek ini dirancang dengan fokus pada kejelasan hierarki informasi dan kemudahan navigasi pengguna agar masyarakat dapat mengenali ciri-ciri modus penipuan finansial dengan cepat.

## Link Live Demo
🔗 [Buka Website Waras Finansial](https://waras-finansial.vercel.app)

## Fitur & Sorotan Desain
* **Hero Section & Navigasi Cepat:** Alur masuk yang langsung mengarahkan pengguna ke bagian edukasi modus penipuan atau area pengecekan tawaran.
* **Edukasi Modus Penipuan:** Penyajian poin-poin jebakan investasi bodong yang ringkas dan mudah dipindai (*scannable*).
* **Antarmuka Cek Tawaran:** Tata letak formulir input teks dan wadah hasil analisis yang bersih serta mudah dipahami.

## Teknologi yang Digunakan
* HTML5 & CSS3 (Custom Styling)
* Python Flask (Routing & Deployment via Vercel)
